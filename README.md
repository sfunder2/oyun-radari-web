# Oyun Radarı

GitHub Pages yayın dosyaları. Steam, Xbox, PlayStation ve Nintendo Switch fiyat karşılaştırması; mevcut Metacritic/OpenCritic puanları ve fiyat/puan göstergesi.

Canlı veriler ayrı sunucu API’sinden alınır. Mağaza erişim kısıtları ve veri zamanları arayüzde gösterilir. PlayStation toplu katalog erişimi kısıtlıdır.
